# Tic Tac Toe — The Unbeatable Edition

A portfolio-quality browser game built around a perfect minimax opponent. Choose
your mark, challenge the machine, or pass the device to a friend. Twelve
hand-tuned themes make every match feel like it belongs on a different table.

Built with vanilla HTML, CSS, and JavaScript. No frameworks, no build step, no
dependencies.

**Designed & developed by Muhammad Amin Khan and Munawar Khan.**

## Highlights

- **A genuinely unbeatable AI.** Exhaustive minimax search with alpha-beta
  pruning. Every reachable branch is covered, so the machine cannot lose. Against
  perfect play, the best result available to you is a draw.
- **Two ways to play.** Solo against the machine, or local pass-and-play for two
  people on one device.
- **Choose X or O.** The machine takes the other mark. In local mode, X always
  opens the round.
- **Twelve themes.** Six light and six dark atmospheres, all saveable between
  visits.
- **Thoughtful assists.** Undo, a hint that plays perfect moves, and a live move
  log.
- **Persistent records.** Scores, streaks, theme, mode, mark, and sound
  preference are stored locally on your device.
- **Generated sound.** Tactile audio cues are synthesized in the browser with
  the Web Audio API — no audio files to load.
- **Keyboard first.** The whole game can be played and navigated without a
  mouse.
- **Responsive and accessible.** Native dialogs, live status announcements,
  visible focus states, reduced-motion support, and layouts tested down to 320px.
- **No external assets beyond the typefaces.** The interface, icons, favicon,
  grain texture, and game pieces are all CSS, SVG, or generated in code.

## The perfect opponent

The engine in `engine.js` is a full minimax solver. It scores every legal branch
from the current position, prefers faster wins and slower losses, and breaks ties
randomly among equally perfect moves so the machine stays varied without ever
weakening.

The claim is deliberately precise: **the AI never loses, but it does not always
win.** Tic Tac Toe is a solved draw, so a perfect human line ends in a draw. That
is the best result available — and the game says so plainly.

`engine.test.js` proves the guarantee by enumerating every possible human
sequence against the engine as both X and O. Run it with:

```bash
node engine.test.js
```

Expected result:

```text
  ok  detects every winning line
  ok  detects a draw
  ok  returns -1 when no move is legal
  ok  is unbeatable as O against every possible human line
  ok  is unbeatable as X against every possible human line
  ok  takes an immediate win
  ok  blocks an immediate loss
  ok  can randomize among equally perfect moves without breaking

All 8 engine checks passed.
```

## Run it locally

There is nothing to install or build. Either open `index.html` directly, or
serve the folder for the most reliable local-storage and font behavior:

```bash
python -m http.server 4173
```

Then visit <http://localhost:4173>.

## Controls

| Action | Input |
| --- | --- |
| Place a mark | Click or tap a square, or focus it and press `Enter` / `Space` |
| Move around the board | Arrow keys |
| Jump to first / last square | `Home` / `End` |
| New round | `N` |
| Undo | `U` |
| Hint | `H` |
| Theme sheet | `T` |
| Close a dialog | `Esc` |

Hints are generated by the same engine, so they show the perfect continuation.
Undo takes back both the machine’s reply and your move in solo mode.

### Saved data

The game uses three local-storage keys:

- `ttt.theme` — the selected theme
- `ttt.prefs` — mode, mark, and sound preference
- `ttt.stats` — solo and local records, including recent form

Nothing is sent to a server. Scores can be cleared from the Record panel;
everything can be reset from the About dialog.

## Accessibility notes

- Native `<dialog>` elements with focus management and `Esc` to close.
- Board squares are real buttons with row/column labels (`A1` … `C3`).
- Turn and round changes are announced through a polite live region.
- All themes are checked for readable contrast; focus rings remain visible.
- Animations respect `prefers-reduced-motion`.
- Layouts adapt from wide desktop grids to a single-column 320px view.
